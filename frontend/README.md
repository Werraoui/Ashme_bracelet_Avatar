# Ashtme Frontend (Flutter)

This folder contains the Flutter UI for the Ashtme mobile app (Android).

## Run locally

1) Install Flutter + Android toolchain.
2) From this folder:

```bash
flutter pub get
flutter run
```

If you prefer generating full platform folders from Flutter templates, you can run:

```bash
flutter create .
```

Then re-run `flutter pub get` and `flutter run`.
